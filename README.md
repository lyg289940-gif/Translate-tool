# LexaDesk 办公智译

**LexaDesk 办公智译**是一款面向高频职场沟通与**汽车零部件制造业**打造的极简浅色智能翻译与文本润色工作台。专为解决日常办公中“中文草稿零散、语序跳跃、口语化或中英混杂”的痛点而设计——在严格尊重原文事实、绝不凭空捏造的前提下，完成语义重构、场景适配、用词分档润色与对比核验。

---

## 核心特性

### 1. 双核翻译与润色模式
- **中 → 英翻译润色**：智能梳理口语化、逻辑跳跃或缺少主语的零散中文草稿，先还原完整意图，再翻译为地道自然的职场英文。
- **中英混杂 · 纯英润色**：统一中英文夹杂消息或语法欠佳的英文草稿，输出连贯得体的目标英文，并支持自动识别语种偏差与一键切换模式。

### 2. 严格防捏造与意图核验（Strict Faithfulness）
- **零捏造原则**：绝不擅自添加原文未提及的日期、时间、人物、数据指标或交付承诺。
- **意图梳理核验**：输出区域同步展示整理后的中文原意摘要；当原文存在模糊指代或缺失细节时，以「边界保留 / 待确认细节」提示明确告知处理方式。
- **中文回译核对**：一键展开成品英文的中文回译，快速核对语气轻重与细微语义。

### 3. 九大办公与工程沟通场景
- **日常口语**：自然流畅的口语对话，避免生硬书面腔。
- **Teams / 即时聊天**：重点前置、简短清晰，适合同事高频协同。
- **常规邮件回复**：得体有礼、结构清晰的日常跨团队与供应商往来邮件。
- **正式邮件回复**：严谨考究，适用于外部 OEM 客户、高层汇报与正式升级沟通。
- **会议纪要与汇报**：条理分明，突出结论与行动项。
- **技术协作沟通**：准确保留零件号、系统标识与技术约束。
- **PPT 汇报**：精炼上屏要点、平行句式与标题动宾结构，适配幻灯片排版。
- **演讲表达**：兼顾口语节奏感与听众视角，适合宣讲与全员沟通。
- **APP 开发文案**：专为界面按钮、弹窗提示、空状态与报错微文案设计，原样保留 `{name}`、`%s`、`{{count}}` 等代码占位符。

### 4. 三档英语用词分类
- **简单用词**：高频基础词汇，短句直白，零理解门槛。
- **中等商务**：地道标准职场表达，专业自然。
- **高等精炼**：高阶精准词汇与凝练句式，凸显专业深度；结果页底部支持一键切换其他档位快速对比。

### 5. 汽车零部件制造业专业定位与词汇包
- **产品与工艺精准定位**：支持切换「汽车零部件制造业 / 通用办公」模式，可定位具体产品方向（动力总成与电驱、动力电池与热管理、底盘与制动、车身结构与一体化压铸、内外饰、汽车电子与线束）及制造工艺（压铸、冲压、注塑、CNC 机加工、焊接、表面处理、总装 EOL、IATF/PPAP/8D），并支持填写精确零件或工位锚点。
- **行业词汇包一键导入**：专属词汇表内置 4 套汽车制造专业术语包（压铸与 CNC 机加工、冲压/注塑与焊接、IATF/PPAP/8D 质量交付、电驱/电池包与底盘零件），支持去重导入、自定义增删、大小写锁定及 JSON 导入/导出。

### 6. 润色对比高亮、偏好模板与本地存储
- **润色对比高亮**：混杂/纯英润色模式下采用逐词级 Diff 算法高亮增删差异；中译英模式下高亮关键表达并支持点击查看原文线索与选词理由。
- **自定义偏好模板**：可配置美式/英式拼写、篇幅精简度、语气温度、邮件首尾包裹策略、保留换行结构及高优先级补充指令，支持保存、复制与切换多套模板。
- **免登录本地存储**：所有偏好设置、模板、专属词汇表及最近 100 条历史记录（支持检索与星标收藏）均即时持久化在浏览器 `localStorage` 中，打开即用。

### 7. 快捷键与悬浮球模式
- 内置可自由拖拽并自动贴靠视口边缘的 **悬浮球速译浮窗**。
- 在支持的 Chromium 浏览器中，支持点击「置顶小窗」通过 Document Picture-in-Picture API 弹出独立桌面浮窗，方便在 Teams / Outlook 旁随时对照翻译。

| 快捷键 | 功能说明 |
| :--- | :--- |
| `Ctrl / ⌘ + Enter` | 在主工作台或悬浮窗内执行翻译与润色 |
| `Ctrl / ⌘ + Shift + C` | 一键复制当前工作台输出译文 |
| `Alt + Space` 或 `Ctrl / ⌘ + K` | 开启 / 展开或收起悬浮球速译浮窗 |
| `Esc` | 收起已展开的悬浮球浮窗 |

## 技术栈

- **前端框架**：React 19 + TypeScript + Vite
- **样式与图标**：Tailwind CSS v4 + Lucide React
- **服务端代理**：Node.js + Express (`server.ts`)
- **AI 能力**：Google GenAI SDK (`@google/genai`，使用 `gemini-4-hydrogen` 模型与结构化 JSON Schema 输出)

## 快速开始

### 1. 环境准备
- Node.js 20+（推荐 Node.js 22+）
- 有效的 Gemini API 密钥（`GEMINI_API_KEY`）

### 2. 配置环境变量
参考 `.env.example` 配置运行时环境变量（请勿将真实密钥提交至代码仓库）：

```env
GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
APP_URL="http://localhost:3000"
```

### 3. 安装依赖并启动开发服务

```bash
npm install
npm run dev
```

服务默认监听 `http://localhost:3000`，由 Express 统一托管 `/api/translate` 接口与 Vite 前端开发中间件。

### 4. 构建与类型检查

```bash
# TypeScript 静态类型检查
npm run lint

# 构建前端生产包（输出至 dist/）
npm run build

# 启动生产服务
npm start
```

## Netlify 部署说明

项目已内置 `netlify.toml` 与 `netlify/functions/` 无服务器函数（将 `/api/*` 自动代理至 Netlify Functions），支持直接部署至 Netlify：

1. 将代码推送至 Git 仓库并在 Netlify 关联部署（构建命令 `npm run build`，发布目录 `dist`，函数目录 `netlify/functions` 已在 `netlify.toml` 中配置）。
2. 在 Netlify 控制台打开 **Site configuration → Environment variables**，添加环境变量：
   - Key: `GEMINI_API_KEY`
   - Value: 您的 Gemini API 密钥
3. 修改或首次添加环境变量后，点击 **Deploys → Trigger deploy** 重新构建部署即可生效。
